Soit les demi-équations d'oxydoréduction~:
\begin{enumerate}[label=\textbf{\alph*)}]
    \item $\ce{H2_{(g)} <=> 2 H^+_{(aq)} + 2 e^{-}}$.
    \item $\ce{MnO^-_4_{(aq)} + 8 H^+_{(aq)} + 5 e^{-} <=> Mn^{2+} + 4 H2O}$.
    \item $\ce{Au_{(s)} <=> Au^3+_{(aq)} + 3 e^{-}}$ \quad ($\ce{Au}$ est l'or).
    \item $\ce{Fe^3+_{(aq)} + e^{-} <=> Fe^2+_{(aq)}}$.
\end{enumerate}

Écrire le couple d'oxydoréduction associé à chacune de ces demi-équations.
