Une cellule conductimétrique est construite en utilisant deux plaques
métalliques de surface $S=\qty{2,0}{\square\cm}$ séparées par une distance
$\ell=\qty{1,0}{\cm}$.
\begin{enumerate}
    \item Calculer le rapport $\frac{S}{\ell}$ en utilisant les unités SI.
    \item On mesure une conductance $G=\qty{795}{\mS}$ pour une solution
          électrolytique. Calculer la conductivité $\sigma$~; préciser l'unité.
    \item La distance entre les plaques est réglée à $\qty{2,0}{\cm}$. Quelle
          est la conductance pour la même solution~?
\end{enumerate}
