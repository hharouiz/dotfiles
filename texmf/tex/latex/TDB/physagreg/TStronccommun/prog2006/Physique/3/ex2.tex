Le rouge sombre est une radiation lumineuse monochromatique ayant pour fréquence
$\nu=\qty{4.00e14}{\Hz}$.
\begin{enumerate}
    \item Quelle grandeur physique caractérise la couleur <<pure>> d'une
          radiation lumineuse monochromatique~?
    \item Quelle est la longueur d'onde dans le vide de la radiation
          considérée~?
    \item Quelle est la longueur d'onde dans un verre d'indice $n=1,5$ pour
          cette fréquence~?
\end{enumerate}
